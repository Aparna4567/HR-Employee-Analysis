📌 Project Overview

The HR Employee Analysis project focuses on analyzing employee data using Microsoft Excel. The objective is to understand employee demographics, salary distribution, department performance, and employee attrition through data analysis and visualization.

🛠️ Tools & Technologies

- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Excel Dashboard

🧹 Data Cleaning & Preparation

- Removed duplicate records.
- Checked missing values.
- Checked data consistency.
- Created new columns using IF, IFS, SWITCH, and AND functions.
- Performed data transformation and feature engineering.

📊 Key Performance Indicators (KPIs)

1. Total Employees
2. Total Monthly Income
3. Average Monthly Income
4. Average Age
5. Average Years at Company
6. Total Employees Left
7. Attrition Rate
8. Average Job Satisfaction
9. Total Training Hours
10. Average Performance Rating

📈 PivotTable Analysis

- Top 10 Highest-Paid Employees
- Bottom 10 Lowest-Paid Employees
- Employees by Gender
- Average Salary by Department
- Total Monthly Income by Department
- Unique Employees by Department

📉 Dashboard & Visualization

Created charts and visualizations to analyze:

- Employee distribution by gender
- Average salary by department
- Top 10 and Bottom 10 employees
- Employee performance and workforce distribution

📁 Project Files

- "HR_PROJECT.xlsx" – Excel project containing data analysis, PivotTables, KPIs, charts, and dashboard.
- "dashboard.png" – Dashboard preview.

🎯 Project Objective

To gain insights into workforce data and understand employee distribution, income patterns, and attrition using Excel.

📚 Key Learnings

- Data cleaning and preparation
- Excel formulas and functions
- KPI creation
- PivotTable and PivotChart analysis
- Dashboard creation and data visualization
